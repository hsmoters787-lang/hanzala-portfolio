# Muhammad Hanzala Portfolio

Responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Files
- `index.html` — website content
- `styles.css` — responsive styling
- `script.js` — mobile menu and current year
## Preview locally
Extract the ZIP and open `index.html` in your browser. Optional local server:
`python -m http.server 8000` then open `http://localhost:8000`.

## Deploy on Vercel
1. Upload these files to the root of a new GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the repository. Choose **Other** if asked for a framework.
4. Deploy as a static site; no build command is needed.
